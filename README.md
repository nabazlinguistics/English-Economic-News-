# English Economic News Corpus 2026

GitHub Pages-ready static website for the MA thesis **A Corpus-Based Analysis of the Occurrence of Articles in English Economic News** by Nabaz Muhammad Saeed, supervised by Asst. Prof. Dr. Salih Ibrahim Ahmed, University of Raparin.

## Published website

The corpus dashboard is published through GitHub Pages at:

https://nabazlinguistics.github.io/English-Economic-News-/

The website is fully static. Its entry point is `index.html`; styling is in `styles.css`; interactions are in `app.js`; corpus records are split across the JSON files listed in `data/manifest.json`, with outlet totals in `data/summary.json`.

Important: the corpus contains full copyrighted news texts. Keep the researcher’s authorized research-use and publication permissions in mind when deciding whether the GitHub repository and Pages site should remain public.
